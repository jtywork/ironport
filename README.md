# Ironport

Static reference site for the Ironport setting (Andala, Pathfinder).

- `index.html`: landing page
- `map.html`: Plan of the City of Ironport
- `sigils-and-seals.html`: faction sigils, family seals, wax impressions
- `catalog.html`: symbol catalog
- `images/`: all artwork, filed by catalog ID

No build step. Served as-is by GitHub Pages from the repository root. `.nojekyll` disables Jekyll processing.
