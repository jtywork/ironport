# Ironport

Player guide and reference site for the Ironport setting (Andala, Pathfinder).

- `index.html`: guide home
- `city.html`, `crown.html`, `people.html`, `faith.html`, `history.html`, `zephyrite.html`, `calendar.html`
- `districts/`, `factions/`, `houses/`: one page per district, faction or order, and noble house
- `map.html`, `sigils-and-seals.html`, `catalog.html`: map and reference pages
- `assets/guide.css`: shared styles and menu
- `images/`: artwork, filed by catalog ID

Static HTML, no build step. `.nojekyll` disables Jekyll processing.
This is the player edition: GM-only material is kept out of this repository.
